# Spotify UI Clone

A simple Spotify Web Player UI clone built using HTML and CSS. The project recreates the look and feel of Spotify's music player with a clean dark theme and responsive layout.

## Features

- Spotify-inspired dark user interface.
- Sidebar with Home, Search, and Your Library.
- Recently Played, Trending Music, and Featured Charts sections.
- Music player with playback controls and progress bar.
- Responsive layout for different screen sizes.
- Hover effects on cards and buttons.

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension.
